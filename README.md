# Nitro-Cooler

**Nitro-Cooler** is an alternative to **Acer NitroSense** for Acer Nitro laptops.

This project is a **fork of AeroForge NitroSense Alternative**, with additional changes and improvements made for my own version of the project.

## Original Project

This project is based on **AeroForge NitroSense Alternative** by Noah Cabral.

Original repository:

https://github.com/noahcabral/aeroforge-nitrosense-alternative

Please refer to the original repository for the upstream project and its original documentation.

## About

Nitro-Cooler aims to provide Nitro laptop users with an alternative way to manage and monitor features normally provided through Acer NitroSense.

The goal is to provide a lightweight and open-source alternative while continuing to build upon the work of the original AeroForge project.
